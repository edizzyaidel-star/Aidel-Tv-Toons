How AIDEL TOONS Studio works

This first version includes a procedural 3D stage, three original placeholder characters, simple mouth/bounce animation, lyrics editing, audio upload and browser recording.

For AI-generated singing and cinematic video clips, connect a trusted provider workflow to the backend webhook endpoints. Never put provider API keys in this website's JavaScript or GitHub repository.

Character models and animation can be upgraded later with rigged 3D assets, facial blendshapes and phoneme-level lip-sync.
